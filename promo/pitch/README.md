**Дайын видео:** [`video/toq-burger-pitch-9x16.mp4`](video/toq-burger-pitch-9x16.mp4) (~60 МБ жеңіл нұсқа, H.264 + AAC, репода тікелей сақталған).
Толық сапалы мастер `render.mjs` арқылы `out/` ішіне жасалады және репоға салынбайды.

## Файлдар
- `script.json` — дауыс мәтіні (әр сахнаға бір сөйлем). «Комбо» сөзі TTS-ке `Ком-бо` деп беріледі — әйтпесе дауыс «камбо» деп оқиды (формант талдауымен тексерілген).
- `timeline.js` — сахналардың уақыты, дауыс сөздеріне байланған кадр/дыбыс оқиғалары. Интро «0»-ден бұрын (`START = -8`) тұрады.
- `index.html` — анимацияның өзі (`renderAt(t)`). Браузерде `index.html?play`, `index.html?t=30` немесе `?safe` (TikTok интерфейс аймақтары) деп ашып көруге болады.
- `audio.mjs` — музыка + SFX синтезі, дауысты орналастыру, ducking → `mix.wav`.
- `render.mjs` — headless Chromium/Edge арқылы барлық кадрды рендерлеп, MP4 жасайды.
- `fonts/` — Montserrat және Unbounded (OFL, @fontsource), офлайн рендер үшін.
- `shots/` — нақты сайттың скриншоттары, `img/` — бургер суреттері мен логотип.

## Қайта жасау
```bash
npm install
node tts.mjs            # барлық дауыс (тек кейбірі: node tts.mjs s0,s8,s10)
node prep.mjs           # сөз уақыттарын vo/words.js-ке жинау
node audio.mjs          # mix.wav
node render.mjs         # out/toq-burger-pitch-9x16.mp4 (~20 мин, 4 ағын)
```
Мәтінді өзгерткен соң `tts.mjs` → `prep.mjs` → `audio.mjs` → `render.mjs` ретімен қайта іске қосыңыз.
Сөйлем ұзарса, `timeline.js` ішіндегі сахна шекараларын (`a`, `b`, `vo`) сәйкестендіріңіз.

Талап: Node 22+, ffmpeg, Chromium немесе Microsoft Edge (`CHROME=/path/to/browser` арқылы көрсетуге болады).

# TOK BURGER — WhatsApp OTP бот

Сайт кіру кодын осы сервиске жібереді (`POST /send`), ал бот оны WhatsApp арқылы клиентке жеткізеді.
Сайт кодын осы сервис арқылы жібереді (`POST /send`), бот доставляет его клиенту в WhatsApp.

> ⚠️ **Маңызды / Важно:** `whatsapp-web.js` — ресми емес кітапхана. WhatsApp нөмірді шектеуі немесе бұғаттауы мүмкін.
> Бот әдейі баяу және «адам сияқты» жібереді, бірақ 100% кепілдік жоқ. Ұзақ мерзімге ресми WhatsApp Cloud API-ге көшкен дұрыс
> (сайттағы `WhatsAppService` интерфейсі мұны сайттың кодын өзгертпей жасауға мүмкіндік береді).
> `whatsapp-web.js` — неофициальная библиотека, бан номера возможен. Для долгосрочной работы рекомендуется официальный Cloud API.

## 1. Іске қосу / Запуск (ПК немесе VPS, Node 20+)

```bash
cd whatsapp-bot
npm install
cp .env.example .env        # WHATSAPP_BOT_TOKEN = сайттағы мәнмен бірдей
npm start                   # терминалда QR шығады
```

Ресторанның WhatsApp-ы → **Связанные устройства → Привязать устройство** → QR-ды сканерлеңіз.
Сессия `./.wwebjs_auth` ішінде сақталады, қайта сканерлеу керек емес.
QR-ды браузерде де көруге болады: `GET /qr` (`Authorization: Bearer <токен>` тақырыбымен).

### pm2 (тұрақты жұмыс / постоянная работа)

```bash
npm i -g pm2
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup     # компьютер қайта қосылғанда автоматты іске қосу
pm2 logs tok-whatsapp-bot
```

Тек **бір** инстанс іске қосыңыз — бір WhatsApp сессиясын бөлісуге болмайды.
VPS (Ubuntu) үшін Chromium керек болуы мүмкін: `sudo apt install -y chromium` және `.env`-ге `PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium`.

## 2. Интернетке шығару / Публикация

Сайт (Cloudflare) ботқа HTTPS арқылы жетуі керек:

- **Cloudflare Tunnel (ПК үшін ең оңай):**
  `cloudflared tunnel --url http://localhost:3001` → берілген `https://....trycloudflare.com` мекенжайын алыңыз
  (тұрақты домен үшін Cloudflare аккаунтында аталған туннель жасаңыз).
- **VPS:** nginx + HTTPS (Let's Encrypt) → `http://127.0.0.1:3001`.

Содан кейін сайттың орта айнымалыларында / затем в переменных окружения сайта:

```
WHATSAPP_BOT_URL=https://<сіздің-туннель-немесе-домен>
WHATSAPP_BOT_TOKEN=<.env-тегі токенмен бірдей>
```

Тексеру / проверка: `curl https://<url>/health` → `{"ready":true}`.

## 3. Бан қаупін азайту / Как снизить риск бана

Ботта бар / Уже встроено:
- бір уақытта бір хабарлама (кезек), әр түрлі алушылар арасында 2–6 с кездейсоқ үзіліс;
- бір нөмірге: 10 минутта 3, тәулігіне 8 хабарламадан артық емес; жалпы сағаттық/тәуліктік лимит (`.env`);
- жібермес бұрын нөмірдің WhatsApp-та тіркелгенін тексереді (жоқ болса — 422);
- «жазып жатыр…» күйі, ұзындыққа сай кідіріс, чатты оқылды деп белгілеу;
- OTP мәтінінің 4 нұсқасы кезектесіп тұрады (код, 5 минут және «никому не сообщайте» әрдайым бар);
- хабарламада сілтемелер жоқ (сілтеме бар болса 400);
- кіріс хабарламаға тәулігіне бір рет сыпайы автожауап;
- ажырағанда автоматты қайта қосылу (backoff); логтарда код пен мәтін жоқ, нөмір жасырылған.

Сіз жасауыңыз керек / Что сделать вам:
1. **Бөлек нөмір** алыңыз (WhatsApp Business), жеке нөмірді қолданбаңыз.
2. Нөмірді **«жылытыңыз»**: 1–2 апта қалыпты қолданыңыз (профиль суреті, аты «TOK BURGER», сипаттама, бірнеше нақты чат).
3. Алғашқы күндері лимиттерді төмен ұстаңыз (`GLOBAL_PER_HOUR=30`, `GLOBAL_PER_DAY=150`).
4. Клиенттерді ресторан нөмірін контактіге сақтауға шақырыңыз; бот нөміріне жазғандарға жауап беріледі.
5. Ешқашан жарнама/рассылка жібермеңіз — тек сайтта клиент өзі сұраған кодтар.
6. Бот құрылғыдан шығып қалса (`ready:false`), QR-ды қайта сканерлеңіз; сайт бұл кезде «код жіберілмеді» деп адал хабарлайды.
